# لوحة تحكم متجر مستحضرات التجميل (Cosmetics Store Admin Dashboard)

لوحة تحكم احترافية وعصرية لإدارة متجر مستحضرات التجميل، مبنية باستخدام **Next.js 15** و **Tailwind CSS**.

## التقنيات المستخدمة
- **Next.js 15 (App Router)**: لأداء عالٍ وتجربة مستخدم سلسة.
- **Redux Toolkit & RTK Query**: لإدارة الحالة والتعامل مع الـ API.
- **Tailwind CSS**: لتصميم عصري وسريع الاستجابة.
- **Framer Motion**: لإضافة تأثيرات بصرية وأنيميشن.
- **React Hook Form & Zod**: للتحقق من صحة البيانات في النماذج.
- **Lucide React**: للأيقونات العصرية.


## المميزات
- **نظام المصادقة**: تسجيل دخول المسؤول وحماية المسارات باستخدام JWT.
- **إدارة الأقسام**: CRUD كامل للأقسام مع رفع الصور.
- **إدارة المنتجات**: CRUD كامل للمنتجات (الاسم، السعر، القسم، الوصف، والصورة).
- **إدارة المراجعات**: معرض لصور مراجعات العملاء مع إمكانية الإضافة والحذف.
- **إحصائيات ذكية**: عرض إجمالي المنتجات والأقسام والمستخدمين في لوحة التحكم.
- **دعم اللغة العربية (RTL)**: الواجهة بالكامل باللغة العربية.
- **تصميم متجاوب**: يعمل بكفاءة على جميع الشاشات.

## المتطلبات
- Node.js 18 أو أحدث.
- الباك إند يعمل محلياً (على منفذ 5000).

## التثبيت والتشغيل

1. انتقل لمجلد الفرونت إند:
   ```bash
   cd frontend
   ```

2. تثبيت المكتبات:
   ```bash
   npm install
   ```

3. تشغيل وضع التطوير:
   ```bash
   npm run dev
   ```

4. لبناء نسخة الإنتاج:
   ```bash
   npm run build
   npm start
   ```

## إعدادات البيئة (.env.local)
تأكد من وجود رابط الـ API الصحيح:
```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

## استخدام Docker
يمكنك تشغيل المشروع باستخدام Docker:
```bash
docker build -t cosmetics-admin .
docker run -p 3000:3000 cosmetics-admin
```

## 🏗️ بنية المشروع (Project Structure)
هذا المشروع مبني باستخدام المعمارية الحديثة لـ Next.js (App Router) مع تقسيم منطقي (Component-Based) يسهل عملية التطوير، الصيانة، وقابلية التوسع (Scalability). المشروع يعتمد على TypeScript لضمان جودة الكود واكتشاف الأخطاء مبكراً. إليك تفصيل شامل لهيكل مجلد `src` الذي سنعمل عليه:

### 1️⃣ مجلد المسارات والصفحات (`src/app`)
يحتوي على جميع مسارات (Routes) التطبيق بناءً على نظام الجذور الجديد لـ Next.js. وهو مقسم إلى شقين رئيسيين:

*   **واجهة المتجر العادية (User Storefront):**
    *   `src/app/page.tsx`: الصفحة الرئيسية (Home Page) التي تعرض لافتات المنتجات (Banners) والأقسام.
    *   `src/app/cart`: صفحة سلة المشتريات.
    *   `src/app/layout.tsx`: التخطيط الأساسي (Root Layout) للمتجر لتغليف المحتوى بالهيدر (Navbar) والفوتر.
*   **لوحة التحكم (Admin Panel):**
    *   `src/app/admin`: المجلد الرئيسي الخاص بلوحة الإدارة.
    *   `src/app/admin/dashboard`: صفحة الإحصائيات العامة للمتجر.
    *   `src/app/admin/categories` | `products` | `reviews`: صفحات وعمليات الإدارة (CRUD) للأقسام والمنتجات ومراجعات العملاء.
    *   `src/app/admin/login`: صفحة تسجيل دخول الأدمن.
    *   `src/app/admin/layout.tsx`: التخطيط الخاص بلوحة التحكم الذي يتضمن القائمة الجانبية (`Sidebar`) منفصلة عن المتجر الأساسي.

### 2️⃣ مجلد المكونات (`src/components`)
يحتوي على مكونات واجهة المستخدم (React Components) مقسمة بشكل منطقي لضمان سهولة إعادة الاستخدام:

*   `admin/`: المكونات الخاصة بلوحة التحكم (مثل: `CategoryForm`, `ProductForm`).
*   `home/`: المكونات المتعلقة بالصفحة الرئيسية للمتجر (مثل: `Banner`, `CategoryFilter`, `ProductCard`).
*   `layout/`: المكونات التخطيطية الهيكلية (مثل: `Navbar`, `Sidebar`, `Footer`, `AdminLayout`).
*   `ui/`: مكونات الواجهة الأساسية منخفضة المستوى (Low-level Components) والتي يتم استخدامها بكثرة في مختلف أجزاء التطبيق مثل (`Button.tsx`, `Input.tsx`, `Modal.tsx`).

### 3️⃣ إدارة الحالة وجلب البيانات (`src/store`)
يعتمد المشروع على **Redux Toolkit** مقترناً مع مكتبة السحب الفائقة **RTK Query** بدلاً من Fetch أو Axios المعتادة، وذلك لتسهيل الكاشينج (Caching) وإدارة حالات الـ Loading & Error:

*   `api/`: يحتوي على ملف `apiSlice.ts` كنقطة وصل أساسية (Base API). ويتفرع منه عدة ملفات مثل `productApiSlice` و `categoryApiSlice`. تحتوي هذه الملفات على الـ Endpoints (جلب البيانات `query` وتعديلها `mutation`).
*   `slices/`: مخصص لـ Client State مثل ملف `authSlice.ts` لحفظ وتحديث حالة تسجيل دخول المستخدم (Token & User Info).
*   `index.ts`: ملف الإعداد الرئيسي (Store Setup).

### 4️⃣ الملفات التأسيسية المساعدة (`src/utils` & `src/hooks`)
*   `utils/`: ملفات مساعدة تؤدي وظائف صغيرة ومحددة. أبرزها ملف `cn.ts` الذي يستخدم مكتبات `clsx` و `tailwind-merge` لدمج فئات Tailwind CSS بطريقة ذكية وتلافي التعارض.
*   `hooks/`: مخصص لبناء دوال (Custom Hooks) مخصصة لإعادة استخدام منطق معين (Logic) داخل المكونات.

### 5️⃣ إعدادات التزويد ومزود الحالة (`src/providers.tsx`)
ملف مسؤول عن احتواء (Wrap) المشروع بالمزودات (Providers) مثل `Next-Redux Provider` لضمان وصول حالة التطبيق لجميع الـ Components.
